- Added editor setup snippets for `bin/rector-warm-lsp` (#55): Neovim (native `vim.lsp.config` plus an `nvim-lspconfig` alternative), Helix (`languages.toml`), and Sublime Text (LSP package `LSP.sublime-settings`), with PhpStorm/LSP4IJ documented as a UI wizard walkthrough since it has no project-file snippet to give.
