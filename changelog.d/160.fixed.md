- Fixed: applying an LSP code action edit against a CRLF-line-ending PHP file could mix line endings in the result -- `RectorDiffParser::hunkNewText()` rejoined a hunk's replacement lines with a hardcoded `\n` regardless of the source file's own convention. It now detects the file's line-ending style from the diff's own unchanged/removed lines and rejoins with that instead, so a CRLF file's applied fix stays CRLF end to end (#160).
