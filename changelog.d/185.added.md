- Added #185: warm single-file dry runs (MCP `rector_process` and LSP diagnostics) are served by one long-lived session child that keeps PHPStan's reflection and Rector's rule state between calls, instead of forking a fresh child from the pristine worker every time. The session tracks every file PHPStan parsed or PHP included, every file it analysed, and every project directory listing; any change starts a fresh session from the pristine worker, so the answer stays the same as a cold `rector process`. A file whose classes only it declares, and write calls, still fork from the pristine worker; an editor buffer's temp copy runs in a child forked from the session. `MCP_RECTOR_WARM_SESSION=0` turns it off; `MCP_RECTOR_WARM_SESSION_LOG=1` logs what served each call on stderr. No change without pcntl (Windows).
