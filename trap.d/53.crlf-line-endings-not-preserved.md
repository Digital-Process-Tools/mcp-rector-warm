#53 self-review (oss:auditor pass) flagged a reasoned-not-observed cross-platform
gap in `src/Lsp/RectorDiffParser.php` / `bin/rector-warm-lsp`'s codeAction edits:
`RectorDiffParser::hunkNewText()` rejoins a hunk's kept lines with a hardcoded
`"\n"`, regardless of what line-ending convention the original file actually used.
This repo has no `.gitattributes`, so a Windows checkout of the new
`tests/Fixtures/lsp-project/*.php` fixtures under the still-common
`core.autocrlf=true` git default would pull them in as CRLF -- and CI here
(`.github/workflows/tests.yml`) runs `ubuntu-latest` for all three jobs, so nothing
in this repo's own gate would ever exercise that path. Not confirmed broken (no
Windows machine or CI leg was available to the auditor or the developer lane), so
this is reasoned, not observed. Rector's own diff generation may already preserve
per-line endings faithfully (each parsed line, before the marker character is
stripped, still carries a source `\r` if the original split point was `\r\n`,
since `RectorDiffParser::parseHunks()` splits on bare `\n` only) -- but the
re-`implode("\n", ...)` in `hunkNewText()` would still produce a mixed-ending
result for the LAST reconstructed line as trailing punctuation, and the E2E
oracle test (`tests/E2E/test_lsp_diagnostics.py::test_code_action_edit_matches_a_cold_rector_apply`)
compares the LSP-applied text against a cold `rector process` run on the same
CRLF file, which could disagree for reasons having nothing to do with the code
under test.

Ranked (per skills/manager/phases/findings.md) as `fails-to-preserve`, non-blocking
-- ships behind this trap.d fragment rather than a filed issue, per the ranking
table's "can ship behind a trap.d fragment" row. Worth `/oss:curate` deciding
whether this becomes a jit-context rule (e.g. "a diff/patch reconstruction
touching file content needs an explicit CRLF-preserving test, or an explicit,
loud skip naming the untested leg") or is deferred until this repo's CI actually
grows a Windows leg, at which point it stops being reasoned and starts being
checkable.
